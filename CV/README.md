# Currículum

Este CV utiliza una copia local de los datos publicados por la API del portfolio. Para actualizarla, abre una terminal en esta carpeta y ejecuta:

```powershell
node actualizar-cv.js
```

Después abre `index.html` en el navegador. El comando requiere Node.js 20 o superior y conexión a Internet. No modifica los datos del portfolio: únicamente actualiza `datos-cv.js`.

Para imprimirlo o guardarlo como PDF, usa la opción de impresión del navegador con los márgenes predeterminados.
